Your output is NOT a source summary.

Your output must be ONE self-contained image-generation prompt whose purpose is to establish the canonical permanent geometry and visual identity of ONE coherent physical object.

CORE OBJECTIVE

Convert the supplied idea into a geometry-first canonical reference that can later serve as the identity anchor for: multi-view reference generation; identity-preserving image editing; fabrication or construction imagery; finished-product imagery; operational imagery; image-to-video generation; scene continuity; downstream visual production.

The generated reference must establish WHAT THE OBJECT PHYSICALLY IS, not merely what it looks like in one attractive image.

The final image prompt must make the object sufficiently distinctive and structurally constrained that later images can preserve the same identity.

SOURCE INTERPRETATION

Read the entire supplied source before writing. Extract useful information internally into: object class; intended use; dimensions; overall proportions; capacity; spatial organization; primary masses or volumes; silhouette; longitudinal/vertical/radial organization; structural topology; openings; glazing; surfaces; transitions; symmetry or asymmetry; distinctive permanent geometric features; construction logic; engineering constraints; materials when geometrically relevant; temporary or non-geometric information.

GEOMETRY FILTER

Determine whether each source detail is:

A. IDENTITY-CRITICAL GEOMETRY - directly affects permanent silhouette, topology, proportions, massing, structural relationships or recognizable physical form.
B. GEOMETRY-SUPPORTING - helps establish plausible physical construction or spatial organization.
C. NON-GEOMETRIC - interior luxury descriptions, marketing claims, invisible engineering systems, performance claims, lifestyle language, emotional adjectives, brand language.

Prioritize A. Use B only where useful. Do not force C into visible geometry.

A stated cabin count does not automatically require the same number of exterior windows. An automation system does not need a visible exterior component. Noise insulation does not become a decorative geometric feature. Water-treatment equipment does not need to appear externally. Luxury language must not be translated into arbitrary ornament.

Translate abstract design ideas into geometry only when a physically meaningful interpretation exists.

DESIGN COMPLETION

Source material will often be incomplete. When it is, you have full authority to design the missing geometry yourself: massing, arrangement, aperture topology, proportions and structural logic. Design decisively and completely.

A prompt that fills its gaps with the typical example of the object class has FAILED, however plausible it reads. The typical example is what the image model already produces without you.

Prefer physically plausible and buildable solutions. Avoid arbitrary decorative features and contradictory geometry. Everything you add must belong to one coherent object that could actually be built.

Never pretend an invented dimension or feature came directly from the source.

Within the image prompt, distinguish exact supplied constraints from reasonable derived or approximate constraints when necessary.

If only one major dimension is supplied, design the remaining proportions rather than defaulting to the class average.

If the source supplies dimensions, counts, topology or explicit geometric relationships that do not contradict each other or the class rules below, preserve them.

ONE DESIGN ONLY

Create exactly ONE design. Never output alternatives such as Option A, Option B, Option C, or multiple possible geometries. Resolve ambiguity into one coherent canonical configuration. All geometry statements must describe the same physical object.

CANONICAL IDENTITY

Define a small but strong set of permanent identity invariants. These should survive: raw fabrication; construction; unfinished state; completed finish; different lighting; different environments; different camera angles; operation; and video generation.

Prefer identity based on: silhouette; primary volume count; massing progression; proportion; major structural breaks; primary curvature; characteristic edge lines; bow/stern relationships for superyachts; front/rear relationships for vehicles; wing/fuselage relationships for aircraft; facade/massing relationships for architecture; leg/body/back relationships for furniture; enclosure/control-surface relationships for machines; opening topology; permanent terraces; major apertures; major overhangs; permanent geometric signatures.

Avoid defining identity primarily through: paint; color; logos; text; furniture; people; landscaping; temporary equipment; lighting; reflections; weather; scenery.

PRIORITY SYSTEM

P0 - IDENTITY: the smallest set of features whose loss would cause the object to become a different design.
P1 - COUNT / TOPOLOGY: exact counts and structural relationships - number of primary volumes; major tiers; wings; principal openings; supports; terraces; relationships between components; containment; connectivity; symmetry.
P2 - PRIMARY GEOMETRY: shape of major components and how they transition.
P3 - PROPORTION: length, width, height, beam, wheelbase, span, deck height, mass ratios.
P4 - SECONDARY GEOMETRY: openings, apertures, recesses, seams, structural edges, and glazing or rails only where the chosen subject state includes them, plus subordinate permanent features.

Do not invent exact counts unless a count is necessary for stable identity. Once an exact count is declared, preserve it consistently throughout the prompt.

TOPOLOGY BEFORE DECORATION

Always establish what components exist; how many exist; where they are; what connects to what; what contains what; what overlaps what; what is recessed; what projects; what is continuous; what terminates; what is symmetrical - before describing finish or aesthetic appearance.

A beautiful image with incorrect topology is a failed geometry reference.

PROPORTION CONTROL

Use dimensions and ratios whenever the source supports them. Prefer relational constraints over excessive isolated numbers: length-to-width ratio; length-to-beam ratio; height-to-width ratio; wheelbase relative to body length; wing span relative to fuselage; primary volume relative to secondary volume; forebody versus aft-body proportion; tier progression; opening-to-solid ratio.

State the canonical length as one exact figure. If a secondary dimension is inferred, mark it as approximate. Do not generate false precision. Use dimensions primarily to control the silhouette.

Superyacht: overall length is ALWAYS between 100 and 180 metres. A length stated in the source outside that band describes a DIFFERENT vessel - it is context, not a constraint on yours. Choose one exact length inside the band and derive every other proportion from it.

REFERENCE STATE

Choose the visual state that exposes permanent geometry most clearly.

Superyacht: ALWAYS advanced structural fabrication, at the end of rough construction and before any finish is applied. Plating is bare unpainted metal with visible weld seams and frame lines. Apertures are open cut-outs with internal frames, girders and deck edges visible through them. Deck edges terminate in bare plating. The plating surface is dull mill-finish steel: matte and light-absorbing, carrying faint mill scale, shallow oxide patches and shop soiling from handling, with broad weak highlights. This is a rule, not a preference, and it overrides any mention of glazing, railings or applied finish elsewhere in this document.

For other fabricated industrial objects, vehicles, aircraft or machines, an unfinished fabrication-state or neutral prototype-state may be preferable. For architecture, a neutral completed shell, structural model or materially simplified architectural state may be preferable. For products where unfinished construction would obscure rather than clarify identity, use a neutral finished prototype.

The state must serve geometry inspection. Do not select a fabrication state merely because fabrication imagery looks dramatic. A fabrication state describes the SUBJECT's own construction - its plating, seams, frames and open apertures - and never the yard equipment around it. The subject is always shown alone.

CAMERA STRATEGY

Choose ONE master view that reveals the greatest amount of identity-critical geometry. Default preference for elongated objects: front three-quarter view. Use a side/profile view instead when longitudinal proportion is substantially more important than depth information. Use an elevated three-quarter view only when upper-surface topology is identity-critical.

Avoid extreme perspective. Prefer moderate telephoto or normal perspective; low optical distortion; sufficient camera distance; full-object visibility; comparable scale between near and far ends.

Explicitly prevent: fisheye; ultra-wide distortion; extreme foreshortening; accidental top-down views; accidental low-angle hero shots; cropping; perspective that alters canonical proportions.

Camera composition must reveal geometry, not dramatize it.

FRAMING

Keep the entire object inside the frame. Require clear negative space around all extremities. Do not allow the model to crop identity-critical geometry merely to make the image more cinematic. For elongated subjects, generally use landscape framing unless the downstream pipeline explicitly requires portrait orientation. If an output aspect ratio is supplied by the source or caller, preserve it.

BACKGROUND

Use a visually neutral environment for the primary geometry reference unless context is geometrically necessary. Default: plain seamless neutral light-grey studio or equivalent neutral technical environment.

Remove unnecessary people; vehicles; tools; furniture; vegetation; water; dramatic sky; buildings; text; logos; signage; construction clutter; decorative props. Context must never compete with object identity.

State the isolation affirmatively in the generated prompt: the subject stands alone, the background field is uniform on every side of it including directly beneath its lowest point, and the subject touches nothing.

LIGHTING

Use lighting designed to expose form. Prefer soft large-source illumination; neutral color; controlled contrast; readable shading transitions across the subject's own surfaces; even exposure. Lighting should reveal major curvature; planes; edges; setbacks; recesses; overhangs; openings; component transitions. Avoid lighting that hides geometry.

On bare or unfinished metal, keep the specular response low and diffuse so the surface reads as matte material rather than polished sheet.

PHOTOREALISM

Unless the caller explicitly requests another representation, target photorealistic; physically plausible; natural material response; professional technical reference photography; high geometric clarity; low visual noise.

Do not turn the reference into concept art; illustration; blueprint; CAD screenshot; exploded diagram; marketing poster; cinematic advertisement.

NEGATIVE GEOMETRY

Explicitly prohibit likely identity failures. Derive these prohibitions from the object and source. Examples: wrong number of levels; extra volumes; missing components; blunt shape where a sharp termination is required; incorrect symmetry; detached components; random openings; compressed proportions; overly tall massing; incorrect orientation; decorative geometry not present in the canonical design.

Write each prohibition as the COMPLETE STATE THAT MUST BE TRUE INSTEAD, never as a negation. The target model has no negative-prompt channel and treats the words you write as things to draw: "no blunt bow" places a blunt bow in the description, while "the bow terminates in a fine edge meeting the waterline at an acute angle" places the correct shape there.

Negative constraints should protect geometry, not become a generic list of image-generation cliches.
